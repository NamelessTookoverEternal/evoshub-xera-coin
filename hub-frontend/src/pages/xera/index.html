What is XERA?

A digital ecosystem asset, still being built in the open

XERA is a digital ecosystem asset being developed by EVOXERA TECHNOLOGY as part of the broader EVOS ecosystem. It's under active development — what's below is exactly what's live today, and what isn't, so you always know where things stand.

Active in V1

  • XERA account access
  • Wallet
  • 24-hour mining sessions
  • Server-authoritative mining
  • Daily claiming
  • Transaction / ledger history

Not active yet

  • Buying
  • Selling
  • Withdrawals
  • Transfers
  • Exchange trading
  • External blockchain functionality

Disabled features are not guaranteed to launch on any timeline — see the full roadmap and disclosure for how we talk about what's next.

How it works

How XERA mining works

STEP 1

Start mining

You start a mining session from your dashboard.

STEP 2

Session runs

The session runs for 24 hours, timed by the server — not your browser.

STEP 3

Return and claim

Once the session is eligible, come back and claim your reward.

STEP 4

Start again

After claiming, you can start a new 24-hour session right away.

The countdown shown in the app is for display only — the server is always the source of truth for when a session becomes claimable and how much it pays out.
