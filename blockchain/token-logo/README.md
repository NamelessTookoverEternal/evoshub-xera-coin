# EVOXERA (XERA) token logo

`logo.png` is the round, transparent 256x256 PNG (about 33 KB) made from the official coin art.
Use it where a token logo is requested after the mainnet contract is deployed and verified:
- BscScan: the "Update token info" request on the verified token page.
- Trust Wallet assets repository: `blockchains/smartchain/assets/<checksummed token address>/logo.png` (plus `info.json`).
- CoinGecko / CoinMarketCap listing forms.
Each service sets its own current size/format rules; check them when you submit. A 1024x1024 master is at
`hub-frontend/public/assets/images/xera-token-logo-1024.png`.
